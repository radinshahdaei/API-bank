# Free Model/API Repository Brief

## Primary repository

### `cheahjs/free-llm-api-resources`

<https://github.com/cheahjs/free-llm-api-resources>

Use this first.

- Curated list of legitimate services providing free LLM API access or trial credits.
- Explicitly excludes unofficial or reverse-engineered chatbot APIs.
- Includes provider limits and available models.
- Providers listed include OpenRouter, Google AI Studio, NVIDIA NIM, Mistral, Hugging Face Inference Providers, Vercel AI Gateway, Cerebras, Groq, Cohere, and Cloudflare Workers AI.

## Alternatives

### `mnfst/awesome-free-llm-apis`

<https://github.com/mnfst/awesome-free-llm-apis>

- Focuses on LLM APIs with permanent free tiers.
- Endpoints are OpenAI SDK-compatible unless marked otherwise.
- Includes base URLs, model names, context limits, and rate limits.

### `12britz/awesome-free-models`

<https://github.com/12britz/awesome-free-models>

- Broader catalog of free AI resources.
- Covers free APIs, open-weight models, local inference, routers, coding models, agent frameworks, and related tools.
- Use when a hosted API is not required or local inference is acceptable.

### `public-apis/public-apis`

<https://github.com/public-apis/public-apis>

- General directory of free public APIs.
- Not specific to AI or model inference.
